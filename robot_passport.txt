# AIKO ROBOT — ТЕХНІЧНИЙ ПАСПОРТ ПРОЄКТУ (ДЛЯ AI-АГЕНТА)

## ⚠️ КРИТИЧНО ВАЖЛИВА ІНФОРМАЦІЯ ПРО ЕЛЕКТРОНІКУ:
1. **Драйвер моторів:** Використовується класичний **L298N** (а НЕ Waveshare Motor Driver HAT). Код керування двигунами має працювати через пряме перемикання GPIO пінів (IN1, IN2, IN3, IN4, ENA, ENB для ШІМ-швидкості), а не через I2C/PCA9685. Ця схема вже працювала успішно раніше!
2. **Датчики відстані ToF (VL53L0X):** Мультиплексор TCA9548A ПОВНІСТЮ ВІД'ЄДНАНО (через нестабільну роботу). 
3. **Логіка підключення ToF без мультиплексора:** Усі 3 датчики VL53L0X підключені до однієї шини I2C паралельно. Але для розв'язання конфлікту адрес кожен датчик має додатковий дріт **XSHUT**, підключений до окремого GPIO піна Raspberry Pi Zero 2 W. XSHUT Сенсор 1 -> GPIO4, XSHUT Сенсор 2 -> GPIO27, XSHUT Сенсор 3 -> GPIO2
4. **Алгоритм ініціалізації ToF:** При старті `safety.py` або `sensors.py` потрібно притиснути всі піни XSHUT до землі (LOW), а потім по черзі підіймати їх (HIGH) і програмно міняти дефолтну I2C адресу датчика (з `0x29` на кастомні, наприклад, `0x2A`, `0x2B`, `0x2C`), щоб вони не конфліктували.

## Поточні завдання:
- Оптимізувати код ініціалізації датчиків ToF через XSHUT, бо зараз він працює нестабільно.
- Забезпечити плавність ходу двигунів через L298N, щоб старт чотирьох моторів не просаджував живлення Raspberry Pi Zero (використовувати поступове наростання ШІМ/PWM).
